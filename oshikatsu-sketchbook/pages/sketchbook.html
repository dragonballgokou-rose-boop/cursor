スケッチブックを作ろう

画像・テキスト・和紙テープ・ステッカーを並べて、推し活の1ページを組み立てます。 コンビニで印刷できる L判 / 2L判 / ましかく / KGサイズ / A4 などのプリセット、 書き出しは 300dpi の PNG。ドラッグで移動、右パネルでサイズ・回転を微調整。

紙サイズ
セブン / ローソン / ファミマ のマルチコピー機で印刷できるサイズです。

操作のコツ

  • 1本指でドラッグ: 移動
  • 2本指でピンチ: 拡大・縮小・回転（PC ならコーナーの□ ／ 上の↻ハンドルを使用）
  • 背景をタップ: 選択解除
  • 右の編集パネルでも数値で細かく調整できます

コンビニ印刷の手順

  1. 左パネルから紙サイズを選び、内容を作る。
  2. 「PNG 印刷用 (300dpi)」をクリックして PNG をダウンロード。
  3. 各社のアプリ・ネット予約サービスに PNG をアップロード。
    • セブン-イレブン: かんたん netprint / netprint アプリ
    • ローソン / ファミリーマート: PrintSmash / ネットワークプリント
  4. 店舗のマルチコピー機で「写真プリント」または「普通紙プリント」を選び、用紙サイズを合わせて出力。

※ 写真プリントは多くの店舗で L判 / 2L判 / ましかく / KGサイズに対応。A4・A3 は普通紙プリント側です。 フチなし／フチありの選択は店舗の機械で行ってください。
