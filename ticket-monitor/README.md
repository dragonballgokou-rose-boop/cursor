# みんなのチケット リセール出品ウォッチャー

乃木坂46 真夏の全国ツアー2026（明治神宮野球場）の **8/22(土)・8/23(日)** 公演の
リセール出品が「みんなのチケット」個人間マーケットプレイスに現れたら、
**通知してブラウザを開くだけ**のローカル監視ツールです。

> ⚠️ **購入は必ず自分の手で行ってください。**
> 自動購入（ボット購入）は「みんなのチケット」ユーザー利用規約に違反します。
> このツールは検知・通知のみを行い、購入操作は一切しません。

## 前提

- Node.js 18 以上
- 自分のPC（Mac / Windows / Linux）で実行すること

## セットアップと実行

### シンプル版（まず試す）

```bash
cd ticket-monitor
node monitor.mjs
```

ページがJavaScript描画のため、シンプル版では出品が検知できない場合があります。
ブラウザでは出品が見えるのに「出品なし」が続く場合は、下のブラウザ版を使ってください。

### ブラウザ版（確実・推奨）

Playwright で実際にページをレンダリングしてから判定します。

```bash
cd ticket-monitor
npm install
npx playwright install chromium
node monitor-browser.mjs
```

## 設定（環境変数）

| 変数 | デフォルト | 説明 |
|---|---|---|
| `WATCH_KEYWORDS` | `8/22,8/23,08/22,08/23` | 検知したい文字列（カンマ区切り） |
| `CHECK_INTERVAL` | `90` | チェック間隔（秒）。最短60秒 |
| `TARGET_URL` | 乃木坂46フィルタ済みページ | 監視対象URL |
| `NO_OPEN` | - | `1` で検知時にブラウザを開かない |

例: 8/23 だけを2分おきに監視

```bash
WATCH_KEYWORDS="8/23,08/23" CHECK_INTERVAL=120 node monitor-browser.mjs
```

## 検知したら

1. 通知音とOS通知が出て、ブラウザでマーケットプレイスが開きます
2. **すぐに自分でログインして購入手続きをしてください**（リセールは早い者勝ち）
3. 楽天IDでのログイン・支払い方法は事前に設定を済ませておくこと

## 注意

- チェック間隔は60秒未満にできないようにしてあります（サーバーへの配慮）
- 一度検知したキーワードは、掲載が続く間は再通知しません（出品が消えて再出現したら再通知）
- 8/22・8/23 の出品はまだ存在しないため（2026-08-09時点で 8/20・8/21 のみ4件）、
  出るかどうかは出品者次第です
